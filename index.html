Passvault

PassVault Project

Description:

Developed PassVault, a secure and user-friendly password manager and generator, built entirely with HTML, CSS, and JavaScript. As the sole developer, I designed the entire application from concept to deployment, focusing on balancing security, usability, and performance.


The app enables users to generate customizable passwords and store them securely using localStorage for on-device data persistence. I implemented features such as copy-to-clipboard, password history tracking, and deletion functionality, ensuring smooth performance and intuitive interaction across both desktop and mobile screens.


A key challenge was designing a simple encryption mechanism for saved passwords while maintaining ease of use. Through extensive debugging and testing, I refined the logic to ensure reliability, security, and responsiveness. This project strengthened my skills in JavaScript data handling, DOM manipulation, and front-end logic optimization, and it showcased my ability to manage a complete project lifecycle independently — from ideation to final deployment.

Text Analyzer

Text Analyzer Project

Description:

Built a real-time Text Analyzer tool that provides instant insights into written text, including word count, character count (with and without spaces), sentence count, and paragraph count. The project was developed using HTML, CSS, and JavaScript, with a focus on accuracy, efficiency, and interactivity.


I designed a clean, minimal interface that allows users to enter or paste text and view results dynamically by clicking the count button. The main challenge was creating efficient string manipulation algorithms capable of handling edge cases like extra spaces, punctuation variations, and inconsistent formatting. Through iterative testing and debugging, I optimized the tool to deliver fast and reliable results.


The success of this project lies in its simplicity and practicality — making it useful for students, writers, and professionals who need quick textual insights. Beyond its technical execution, the Text Analyzer reflects my ability to design functional, user-centered tools and my commitment to clean UI design, efficient code, and performance optimization.

Tech Stack

Git, GitHub Pages.

Real-time text analysis (word, character, sentence, and paragraph counts).

Logic Focus
